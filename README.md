# Axiom Device Library

Shared device profiles, setup guides, examples and test results for Axiom.

The aim is to help people connect sensors and actuators, get useful
results quickly, and contribute improvements.

## Integrations

| Integration | Purpose | Status |
|---|---|---|
| [AHT20](profiles/AHT20/README.md) | Temperature and humidity | Draft |

Each integration includes its descriptor, setup documentation, source
information and available test reports.

Compatibility applies to the combinations recorded in those reports.
